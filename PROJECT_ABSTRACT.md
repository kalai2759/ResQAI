# Project Abstract — ResQAI

**ResQAI (Smarter Response. Safer Lives.)** is a full-stack web prototype that supports community disaster preparedness. Built with Python, Flask and SQLite, it lets users report local incidents such as flooding and road blockages, search reports by a unique ID, and view them on an interactive map and a filterable dashboard. A signed-in demo administrator can verify, resolve or reject reports, so unconfirmed information is never presented as verified. An emergency resources directory lists publicly available helplines and official bodies with their sources. A preparedness assistant provides general guidance through a server-side AI integration when an API key is configured, and through a clearly labelled demo mode otherwise. Live weather is retrieved from Open-Meteo when available and is never fabricated when unavailable.

The project emphasises honesty and safety: all sample records are labelled DEMO DATA, the system does not claim to contact emergency services or issue official alerts, and users are directed to official sources and to the emergency number 112 in urgent situations. Security measures include input validation, CSRF protection, password hashing, rate limiting and parameterised queries. It is a prototype for demonstration and has not been deployed with, or used by, real emergency organisations.
