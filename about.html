About ResQAI

ResQAI - Smarter Response. Safer Lives. - is a hackathon prototype that brings preparedness information, community incident reports, a map and an AI assistant together.

What it is

A web application for students, community members, volunteers and organisations to learn how to prepare for disasters, report local incidents, see them on a map and find official emergency resources.

What it is not

  • Not an official emergency service.
  • Cannot dispatch rescue teams or contact emergency services.
  • Does not issue or republish official alerts.
  • Does not say whether roads or shelters are safe or open.

Honest status of data

  • Records labelled DEMO DATA are fictional.
  • Reports are unverified until an administrator changes their status.
  • Helpline numbers are publicly listed but not independently verified here.
  • Weather is live model data from Open-Meteo when reachable, otherwise a clear "unavailable" message.

AI assistant

With an API key configured on the server it uses an AI model for general guidance. Without one it runs in a labelled demo mode with predefined answers. It never replaces official warnings or emergency professionals.

Emergency numbers (India)

Call 112 for any emergency. Confirm numbers on official sources, see the resources page.

Built with

Python, Flask, SQLite, Leaflet and OpenStreetMap, Chart.js, Open-Meteo, plain HTML, CSS and JavaScript.
